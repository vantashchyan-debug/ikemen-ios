# Ikemen GO → iPhone (iOS-порт)

Порт движка Ikemen GO **v1.0.0** на iOS, оптимизированный под **iPhone 12 Pro** (A14, 2532×1170, iOS 14+),
с нативным сенсорным управлением и полной настройкой раскладки.

```
engine/                 исходники Ikemen GO v1.0.0 + iOS-патч (MIT)
ios/src/                нативная оболочка iOS (Objective-C, UIKit)
  main.m                точка входа: SDL → Go (SDL_main)
  IKOverlayView.m       сенсорный оверлей, мультитач, редактор раскладки
  IKSettingsViewController.m   экран настроек
  IKLayout.m            профили, пресеты, JSON, язык макросов
ios/build_ios.sh        сборка .ipa (macOS / GitHub Actions)
ios/package_game.py     упаковка твоей игры в .ipa (работает на Linux)
ios/make_ipa.sh         обёртка над ним
ios/engine-ios.patch    все изменения движка относительно v1.0.0
.github/workflows/ios.yml   CI: собирает .ipa на macOS-раннере
```

## Как получить .ipa

Для компиляции под iOS нужен Xcode, поэтому движок собирается на бесплатном macOS-раннере GitHub.
Твои персонажи, музыка и стейджи на GitHub **не попадают**: они добавляются в .ipa локально, на Linux.

1. Создай репозиторий на GitHub (можно приватный) и запушь эту папку:
   ```bash
   cd ~/Projects/ikemen-ios
   git init -b main && git add -A && git commit -m "Ikemen GO iOS port"
   git remote add origin git@github.com:<твой-логин>/ikemen-ios.git
   git push -u origin main
   ```
2. GitHub → вкладка **Actions** → **iOS IPA**. Сборка запускается сама при пуше, вручную её запускает
   «Run workflow». Первая сборка идёт около 15 минут, следующие быстрее за счёт кэша.
3. Скачай артефакт `Ikemen_GO-ios-N` (zip с `Ikemen_GO-engine.ipa`).
4. Добавь свою игру:
   ```bash
   ~/Projects/ikemen-ios/ios/make_ipa.sh ~/Downloads/Ikemen_GO-ios-1.zip ~/Projects/ikemen ~/Ikemen_GO.ipa
   ```
5. **iOS 26/27:** TrollStore не работает, ставь через подпись Apple ID.
   Без Мака и Windows подойдут **Impactor** (есть под Linux) или **SideStore**: SideStore после первой установки
   сам переподписывает приложение на телефоне. В «Настройки → Конфиденциальность и безопасность» включи
   **Режим разработчика**.
   Также можно через **Sideloadly** или **AltStore** с Windows или Mac: подключи iPhone и войди своим Apple ID.
   На iPhone открой «Настройки → Основные → VPN и управление устройством» и доверься профилю.
   С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней. Сохранения при этом не теряются.

> Если игру всё-таки хочется собирать целиком в CI, положи её в папку `game/` в корне репозитория.
> Тогда workflow сразу выдаст готовый `Ikemen_GO.ipa`. Учти, что игра весит ~470 МБ, а в приватных
> репозиториях лимит минут macOS ограничен.

## Что сделано в движке

- **Рендер Vulkan → Metal через MoltenVK.** Android-рендер GLES 3.2 на iOS невозможен:
  там максимум GLES 3.0, нет геометрических шейдеров и cube-map array.
- **Нативное разрешение Retina.** Swapchain и viewport считаются в пикселях (2532×1170), а не в точках.
  Без этого картинка была бы размыта в 3 раза.
- `runtime.GOOS` на iOS равен `"ios"`, а не `"darwin"`. Все macOS-ветки (portability subset в Vulkan,
  обход палитр под Metal, маппинг геймпадов) включены и для iOS.
- **Сворачивание приложения.** При уходе в фон рендер останавливается: iOS убивает приложения,
  которые рисуют в фоне. Сенсорные кнопки при этом отпускаются.
- **Настройки под iPhone 12 Pro**, применяются при каждом запуске:
  - внутреннее разрешение не выше 1280×720 (игра нарисована под него), вывод на экран в нативных 2532×1170;
  - Vulkan, 60 FPS, VSync, полный экран;
  - MSAA не выше 4×;
  - тени 3D-моделей выключены;
  - BGM не грузится в RAM целиком: FLAC-музыка съела бы сотни МБ;
  - мягкий лимит памяти Go 1.6 ГБ, чтобы iOS не выгружал игру;
  - экран не гаснет во время игры, ориентация только горизонтальная;
  - системные жесты по краям требуют двойного свайпа: случайно выйти из боя нельзя.
- Акселерометр не притворяется джойстиком, поэтому не занимает слот P1.
- **Геймпады** (MFi, Xbox, DualShock, DualSense) работают через SDL сразу после подключения по Bluetooth.

## Сенсорное управление

Кнопка **⚙︎** (сверху по центру) открывает настройки. Её можно передвинуть и уменьшить, но не удалить.

**Редактор на экране** («Редактировать раскладку»):
- перетаскивание пальцем, изменение размера щипком, привязка к сетке, отмена (60 шагов);
- тап по элементу открывает панель: − / + / Свойства / Копия / Скрыть / Удалить;
- «＋ Добавить» добавляет кнопку, клавишу, макрос или ещё одну крестовину/стик.

**У каждого элемента настраиваются:**
- подпись, видимость, режим показа (всегда / только в бою / только в меню);
- размер, пропорции, форма (круг / скругление / квадрат), точная позиция X/Y;
- зона касания: может быть больше видимой кнопки;
- своя прозрачность и свой цвет;
- **кнопка**: любое сочетание из 14 игровых кнопок (`U D L R a b c x y z s d w m`), например `x+y` одной кнопкой;
  турбо с частотой 2–30 Гц, фиксация (вкл/выкл);
- **клавиша**: Esc, Enter, F1–F12, Pause, ScrollLock, стрелки, буквы, цифры. Даёт доступ к горячим клавишам
  Ikemen и тренировке;
- **макрос**: нумпад-нотация с учётом того, куда смотрит персонаж. Например `236+a`, `623+x`,
  `41236+c:4`, `_:30 a a a`. Есть проверка скрипта и повтор, пока держишь;
- **крестовина**: 8 направлений / 4 направления / фиксированный стик / плавающий стик.
  Настраиваются мёртвая зона, ширина диагоналей в градусах, зона появления плавающего стика
  и возврат на место.

**Глобальные настройки:**
- прозрачность обычная и при нажатии, общий масштаб, стиль (контур / заливка / минимал);
- подписи, анимация нажатия, цвет;
- затухание при бездействии;
- каким игроком управлять (P1–P4);
- скольжение пальца между кнопками, нажатие двух кнопок на стыке;
- вибрация: 5 типов, сила, при отпускании, при смене направления;
- автоскрытие при подключённом геймпаде.

**Профили:** несколько раскладок с переключением, 6 пресетов («Veils of Blood (7 кнопок)»: LP/MP/HP, LK/MK/HK, SP и
кнопка насмешки ↓↓↓↓; 4 кнопки; плавающий стик; крупные кнопки; для левши; только меню), зеркалирование, экспорт и импорт JSON через буфер обмена
или файл.

## Файлы на iPhone

Приложение «Файлы» → «На iPhone» → **Ikemen**:
- `save/`: config.ini, статистика, реплеи, логи (`save/logs`, там же отчёты о вылетах),
  `touch_layout.json`;
- чтобы заменить встроенную папку (`chars`, `stages`, `data`…), положи рядом настоящую папку с тем же
  именем: она будет использоваться вместо встроенной. Так можно добавлять персонажей без пересборки .ipa.

## Ограничения

- **Видеофоны (.webm) не воспроизводятся**: FFmpeg пока не собран под iOS. Затронуты лого и титры
  скринпака (`ik_logo.webm`, `ik_credits.webm`). Вместо видео пустой фон, всё остальное работает.
- Тени 3D-моделей отключены.
- Сетевая игра (netplay/rollback) на iOS не проверялась.
- Нативный iOS-код (Objective-C) не компилировался локально: на Linux нет iOS SDK, первая проверка
  будет в CI. Если сборка в Actions упадёт, пришли лог шага **Build**, и я поправлю.

## Обновление движка

Все правки движка лежат в `ios/engine-ios.patch` (≈420 строк). Чтобы перейти на новую версию Ikemen GO,
положи её исходники в `engine/` и выполни `git apply ios/engine-ios.patch`.
